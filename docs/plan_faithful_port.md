# 忠実移植の計画書（第5段階以降）

作成: 2026-10-10（作業PCの時刻）。対象は `--fiscal port`（財政ブロックの移植版）。

## 1. 現状

方程式リストの式をそのまま使っている部分と、原典と違う扱いをしている部分は次のとおり。

**原典の式をそのまま使っている部分**
- マクロ経済・人口ブロック（`--mode faithful` のとき。`calibrated` はコールレート式など2か所を公表乗数に合わせて変えている）
- 財政ブロックの会計部分（国の一般会計、公共事業関係特別会計、地方財政計画、交付税特会、地方普通会計、その他指標）
- 社会保障ブロックの年金（83本）、その他（10本）、医療・介護の制度別の財政調整・公費負担・保険料
- 普通国債（2026〜2035年度発行分の発行年度×年限の積み上げ）、地方債・臨時財政対策債（経過年数別の積み上げ）

**原典と違う扱いをしている部分（この計画の対象）**

| 番号 | 部分 | 現在の扱い | 乗数への影響 |
|---|---|---|---|
| A | 医療の年齢別の積み上げ（原典465本のうち約370本） | 給付費 = 基準年度の給付費 × 費用の指数 に集約 | なし（人口が変わらないショックでは一致） |
| B | 介護の年齢×要介護度×サービス別の積み上げ（原典609本のうち約570本） | 同上 | なし（同上） |
| C | 年金特例国債・復興債・GX経済移行債・半導体・AI債（54項目） | 年金特例は平均金利で集約、ほかは外生 | 小（残高は合わせて約10兆円） |
| D | 既発の地方債の償還予定 | 2025年度末残高を平均14年で償還すると推定 | 中（法人税・金利ケースの残高比、可処分所得） |
| E | 資料に値がないパラメータ | 推定値（改定率の重み、既裁定者の割合、積立金の実質利回りなど） | 小〜中 |
| F | 既発国債の基準時点 | 2025年度末の銘柄別現在高（原典は2024年度末まで） | 小 |
| G | 方程式リストの読み取りの残り | 誤植と判断して直した式（PATCH、PENSION_PATCH、S_OUIIPRM） | 確認のみ |

A・B は乗数には効かないが、人口が変わるシナリオ（高齢化・健康寿命の延伸など）を原典どおりに回すには必要になる。乗数の再現を目的にするなら D と E を先に、モデルの構造をそろえることを目的にするなら A・B を先にする。

## 2. 作業項目

### A. 医療の年齢別の積み上げ

**原典の式**（社会保障ブロック「医療」）
- 加入者数: `S_MaaINSPbbbbN = S_MaaINSPbbbbN$ * P_POPbbbb`（制度5区分 × 5歳階級 0〜74歳）、後期高齢者は65〜100歳以上
- 一人当たり医療費: `S_MaaCOSTbbbbA` は前年 ×（1 + 診療報酬改定率）。20歳以上は「健康寿命の延伸効果」`S_MPHAEF` で5歳若い階級の費用に近づく
- 医療費 = 一人当たり医療費 × 加入者数、給付費 = 給付率 `$` × 医療費、制度別・年齢区分別に合計

**作業**
1. ひな形の展開: `aa`（制度）× `bbbb`（年齢）、`cccc`（5歳若い階級）を展開する関数を `fiscal_port.socsec_eqs` に加える。0〜19歳と20歳以上で式が2本ある項目（`S_MaaCOSTbbbbA`）、見出しの下に式が欠けている項目（`S_MLECOST6569`）を確認して補う。
2. 集約の式（`SS_COLLAPSED` の医療分）を外す。
3. 人口: モデルの人口ブロックは15〜19歳から70歳以上までしかないので、0〜14歳と75歳以上の5歳階級の人口（`P_POP0004` など）を外生で加える。

**必要なデータ**
- 総務省「人口推計」2024年10月1日現在の男女・5歳階級別人口（e-Stat）
- 国立社会保障・人口問題研究所「日本の将来推計人口（令和5年推計）」の5歳階級別人口（外挿期間の経路。乗数だけなら一定でよい）
- 厚労省「医療保険に関する基礎資料（令和5年度）」の年齢階級別加入者数（p.12〜13、取得済みの範囲で足りる）と、年齢階級別一人当たり医療費
- 給付率（年齢階級別。義務教育就学前8割、70〜74歳8割など）は法定の値

**検証**
- 人口を固定したまま8ケースを回し、集約版と乗数が一致すること（小数第3位まで）を確かめる。一致しなければ展開の誤り。
- 2024年度の制度別給付費が財政構造表の値に戻ること。

### B. 介護の年齢×要介護度×サービス別の積み上げ

**原典の式**（社会保障ブロック「介護」）
- 認定者数: `S_CCICNaaaabbN = 認定率$2 × P_POPaaaa`（年齢9区分 × 要介護度7区分）。認定率は利用状況と重度化予防効果 `S_CPHAEF` で動く
- 受給者数: `S_CCIUaaaabbcN = 利用率$2 × 認定者数`（サービス2区分: 施設等・居宅）
- 一人当たり費用: 前年 ×（1 + 介護報酬改定率 + 補正）、費用 = 一人当たり費用 × 受給者数、給付費は給付率を掛けて年齢別に合計

**作業**
1. ひな形の展開: `aaaa`（年齢9）× `bb`（要介護度7）× `c`（サービス2）。認定率・認定者数（各63）、利用率・受給者数・一人当たり費用・費用（各126）など、約570本になる。
2. 集約の式（`SS_COLLAPSED` の介護分）を外す。

**必要なデータ**
- 厚労省「介護給付費等実態統計」（年齢階級別・要介護度別の受給者数・費用額、施設・居宅の別）
- 厚労省「介護保険事業状況報告（令和6年度年報）」の年齢階級別・要介護度別の認定者数（年報の取得済み資料にない場合は追加で取得）
- A と同じ5歳階級別人口（40〜64歳、65歳以上の5歳階級、95歳以上）

**検証**
- A と同じく、集約版と乗数が一致すること。2024年度の給付費（施設等・居宅）が年報の値に戻ること。

### C. 年金特例国債・復興債・GX経済移行債・半導体・AI債

**原典の式**: 普通国債と同じ形のひな形（発行年度×年限）。年限は債券ごとに違う（年金特例は1・2・5・10年、復興債は1・2・5年、GXは1・2・5・10・20年、半導体・AIは1・2・5・10年）。発行額は各債券の公債金収入と償還額から決まり、復興債・GX・半導体の公債金収入は外生の事業費・財源から決まる。

**作業**
1. `bond_port.py` のひな形の生成を、接頭辞（`BP_`、`BR_`、`BX_`、`BS_`）と年限の組を引数にとる形に一般化する。
2. 年金特例国債の集約の式（`BOND` の `M_RAVGC`、`ZP_PINTBON`）を外す。
3. 標準ケースの前向きの計算の対象に加える。

**必要なデータ**
- 既発分: GX経済移行債は銘柄別現在高のクライメート・トランジション利付国債（取得済み、4.2兆円）。復興債・年金特例国債は普通国債と同じ銘柄で発行されるので銘柄別には分からない。財務省「国債及び借入金並びに政府保証債務現在高」の種類別残高から総額を取り、普通国債と同じ満期構成で按分する（推定）。
- 外生の事業費（`ZR_FUKKOKEIHI`、`ZX_GXYOSAN`、`ZS_SEMIYOSAN` など）: 2026年度予算の値

**検証**: 金利ケースの国債費・公債等残高比の変化。合計の残高が財務省の種類別残高に戻ること。

### D. 既発の地方債の償還予定

原典では既発分の元金償還 `B_ROP` と利払い `B_DRP` は外生の系列（出所は ILF・MIC、すなわち地方公共団体金融機構・総務省）。現在は平均14年の一定の償還で推定している。

**作業**
1. 統計の調査: 総務省「地方財政状況調査（決算統計）」の地方債現在高の償還予定額、地方公共団体金融機構の資料、総務省の「公債費の将来推計」などで、年度別の元金償還予定と利払い予定が取れるか確かめる。
2. 取れれば `bond_port.lgb_exog_series` を統計の系列に置き換える。取れなければ、地方債の発行実績（地方債計画の年度別発行額、資金区分別の償還年限）から既発債を積み上げて推計する。
3. 臨時財政対策債の既発分（`Z_ROPR`）も同じ方法で分ける。

**検証**: 2024年度の公債費（元金償還・利子）が決算に戻ること。法人税ケース・金利ケースの公債等残高比と可処分所得の変化。

### E. 資料に値がないパラメータの根拠づけ

| パラメータ | 現在の値 | 根拠づけの方法 |
|---|---|---|
| 診療報酬改定率の重み `S_MMIRCCF$`、`S_MMICFWG$`、`S_MMICFPR$` | 0.5、1、1 | 2014〜2024年度の改定率（本体・薬価等）を、賃金・物価の当年・前年の伸びに回帰して推定 |
| 介護報酬改定率の重み `S_CCICFWG$`、`S_CCICFPR$` | 0.5、0.5 | 2015〜2024年度の介護報酬改定率で同様に推定 |
| 既裁定者の割合 `S_PBPRCYA$`、`S_PENRCYA$` | 0.85 | 「厚生年金保険・国民年金事業年報」の年齢別受給者数（68歳以上の割合） |
| 積立金の実質利回り `S_PPIRTRBD$Z`、`S_PPIRTROT$Z` | 0、3% | 2024年財政検証の運用利回りの前提（国内債券・その他資産） |
| 個人向け国債の利率 | 0.5〜0.9% | 財務省の個人向け国債の発行条件（回号別） |
| 地方債のリスクプレミアム `B_RISKPRM` | 0.3%pt | 財政融資資金の貸付金利（20年、据置3年）と10年国債利回りの差 |

それぞれ乗数への感応度を先に調べ、効くものから順に根拠づけする。

### F. 既発国債の基準時点

原典は2024年度末までの既発債を外生にし、2025年度以降の発行分を積み上げる。現在は2025年度末の銘柄別現在高を使い、2025年度発行分も既発債に含めている。2024年度末の銘柄別現在高（令和7年3月末）は財務省のページに現在は載っていないので、国債統計年報か入札結果からの積み上げで再構成できるかを調べる。乗数のショックは2026年度からなので、影響は小さい見込み。

### G. 読み取りの確認

誤植と判断して直した式（`PATCH` の7本、`PENSION_PATCH` の4本、`S_OUIIPRM`）を資料の PDF の画像で確認し直し、判断の根拠を README に残す。

## 3. 進める順序と規模の目安

| 順 | 項目 | 規模 | 乗数への影響 | ダウンロードの承認が必要な資料 |
|---|---|---|---|---|
| 1 | D 既発の地方債の償還予定 | 中（調査が中心） | 中 | 総務省・地方公共団体金融機構の資料 |
| 2 | E パラメータの根拠づけ | 中 | 小〜中 | 診療報酬・介護報酬の改定率の推移、年金事業年報、財政検証 |
| 3 | C 特別な国債 | 中（ひな形の一般化） | 小 | 国債及び借入金並びに政府保証債務現在高、2026年度予算 |
| 4 | A 医療の年齢別 | 大（約370本、データ多い） | なし | 人口推計、将来推計人口、医療給付の年齢階級別データ |
| 5 | B 介護の年齢×要介護度 | 大（約570本） | なし | 介護給付費等実態統計 |
| 6 | F・G 確認 | 小 | 小 | なし |

- 各項目の後に、8ケースの乗数を両モード（calibrated・faithful）で計算し、公表乗数とのずれ（実質GDP、消費者物価、コールレート、可処分所得、基礎的財政収支、公債等残高比）を README の表に追記する。
- A・B は式の数が増えて計算時間が延びる（現在は1モード約4分）。延びが大きければ、年齢別の部分を標準ケースで前向きに解いて固定するなど、国債と同じ扱いを検討する。
- 資料のダウンロードは、そのつど資料名・取得元・大きさを示して承認を得る。

## 4. 完了の判定

- 方程式リストの全ブロックについて、原典の式を使っているか、使っていない理由（資料の欠落・誤植・データがない）が README に書かれている。
- 集約した部分（A・B）を展開しても、人口を固定した乗数が集約版と一致する。
- 推定値の一覧（README「統計で取れず推定した値」）に、根拠のないまま残る値とその感応度が書かれている。
